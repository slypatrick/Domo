# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** Uber Eats clarity + Etsy photo-first warmth (Nov 2026). Buyer side: borderless photo-first product and shop cards, round "+" on the photo, grey pill chips (`--chip`) with black selected (`--cta`), black pill CTAs for cart and checkout. Domo blue (`--brand`) for links, brand and seller tools; status tabs use the black selected pill. One main action per card, rare actions in the `⋯` menu (`omenu`), bottom sheets on phones. Tokens live in `:root` of `app/public/index.html` (light + dark); restyle rules in the "Design upgrade" and "Commerce restyle" CSS blocks. Fonts: Bricolage Grotesque (titles) + Instrument Sans (text); Cairo for Arabic. Sign-in uses the full-bleed Domo-blue hero of domo.tn.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary (exception: the sticky top bar and bottom nav, which keep their 1px border)
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders (exceptions: the blue sign-in hero and shop cover banners)
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving) — exception: the existing unDraw set in `app/public/ill/`, used sparingly, one per screen, never as decorative filler
- Nested scrollbars and icon bloat inside inputs
- Showing or advertising paused features (protected purchase / "Achat sécurisé")

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 normal text, ≥ 3:1 large text, borders and icons; check both light and dark themes and any text on the blue hero
- **Touch / focus:** ≥ 44×44px targets; visible `:focus-visible` ring (brand blue, white on the blue hero); test at 360/390 and 1280, in Chromium and WebKit

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** French first, Arabic (RTL) layer. Plain words for sellers and buyers new to apps; address users with "vous"; never blame the user. Phone placeholders read `ex. 22 123 456`; errors sit under each field.

## Icon library

- **Library:** Project SVG
- **Package / path:** inline SVG sprite in `app/public/index.html` (`<symbol id="i-…">`, used as `<svg class="i"><use href="#i-name"/></svg>` or `ic('name')`)
- **Notes:** Add new icons to the same sprite in the same stroke style. No icon packages, no mixing sets, no emoji as UI icons (the "ع" language button is text, not an icon).

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
