# Domo — logo assets & brand guidelines (v1.0, Nov 2026)

Vector rebuild of the Domo logo (house + drop symbol, Comfortaa Bold wordmark, orange dot).
Brand guidelines: `guidelines/domo-charte-graphique.pdf` (10 pages, French).

| Folder | Content |
|---|---|
| `logo/` | Horizontal, stacked, wordmark — color, white, black, blue, mono-white (SVG) |
| `icon/` | Symbol (color, ink, black, white) and app icon (SVG) |
| `png/` | All logos as transparent PNG, 1200 & 2400 px (icons 512 & 1024 px) |
| `web/` | favicon.ico/.svg, favicon 16/32/48, apple-touch-icon, icon-192/512, maskable-512, site.webmanifest, head-snippet.html |
| `social/` | Profile picture 1080, link preview 1200×630 (white & blue), cover 1500×500 (SVG + PNG) |
| `guidelines/` | Brand guidelines (PDF, HTML, page previews) |
| `src/` | Original artwork and construction notes |

Colours: Bleu Domo `#0133F8` · Encre `#010D36` · Orange `#FE5901` · Brume `#F4F5FA`.
Fonts: Comfortaa Bold (logo, titles) · Nunito (text) · Cairo (Arabic) — all SIL Open Font License.
Before print or trademark filing: check the name and symbol with INNORPI and a prior-art search.
