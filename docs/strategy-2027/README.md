# DOMO 2027 — Strategic masterplan (December 2026 – November 2027)

Prepared 16 November 2026. Strategy and specifications only: no code, database, deployment or production setting was changed. The package suggested in the brief (about 35 files) is consolidated into the 13 files below; every requested section is covered, and the table maps each original file name to where it lives.

| File | Contains (original file names) |
|---|---|
| `00_EXECUTIVE_BRIEF.md` | Executive summary, key decisions, open questions; final synthesis: ten decisions, five mistakes, 90-day plan, end state |
| `01_CURRENT_STATE.md` | Product audit, feature inventory, user journeys, fragmentation verdict, scorecard, defects for Opus |
| `02_MARKET_AND_COMPETITION.md` | Tunisian market facts with sources, market sizing, customer segments, geography, competitive analysis, positioning options |
| `03_STRATEGY_AND_BUSINESS_MODEL.md` | Vision and positioning, brand messaging, business model evaluation, pricing architecture, strategic trade-offs |

| `06_GROWTH.md` | Growth strategy, acquisition playbook, campaigns, content, referrals, retention strategy, partnerships |
| `07_OPERATIONS_AND_RISK.md` | Operating model, procedures, trust and compliance, legal-review checklist, risk register |

**Reading order.** Founder: 00, then 05 and 09. Opus: 10_OPUS_HANDOFF, 10_PRDS, 08, 04. Investor: 00, 11, 05, 02.

**How the documents fit together.** The signup forecast in the model comes from channel capacity in 06. The monthly budgets in 09 sum to the model's base-case operating expenses (20,400 DT). The roadmap in 09 is sized for the staffing in 07 (one founder, no employee). The architecture in 08 supports the batches in 10. Prices in 03 are the model's inputs.

**Using the workbook.** Edit only blue cells on the Assumptions sheet (yellow cells are untested or unknown values). The three scenario sheets and the Summary recalculate. The Sensitivity sheet holds static values computed from the same formulas.
